# 🏢 TrustFix: Tenant-Owner Complaint Management System

**TrustFix** is a modern web-based complaint management system designed to bridge the communication gap between tenants, property owners, and technicians. It focuses on accountability and visual proof through a "Before & After" workflow.

---

## ✨ Key Features
- Evidence-Based Resolution (Before & After Photos)
- Modern Glassmorphism UI
- Technician Performance Tracking
- Feedback & Rating System
- Smart Search & Filtering

---

## 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript  
- Backend: Python (Flask)  
- Database: SQLite  

---

## 🚀 Installation
git clone https://github.com/shrutikasarnaik/TrustFix_Project.git  
cd TrustFix_Project
